# 紙上格局｜A4 網格文件編輯器

這是一個完全獨立、無需安裝套件的靜態網頁專案，不會與上層的「私藏雲」網站共用程式碼。

直接開啟 `index.html` 即可使用；若瀏覽器限制本機下載，可在此資料夾啟動任一靜態伺服器後再開啟。

功能包含：A4 直向／橫向切換、固定位置文字框、可設定列數與欄數的真正表格、獨立圖片與表格儲存格內圖片、拖曳與縮放、網格吸附、模板儲存與編輯、復原重做、本機自動儲存，以及 Word DOCX / PDF 匯出。

Word 匯出使用真正的 `.docx` 格式，每個文字框、圖片與表格都會轉成 Word 的固定頁面座標物件；放在儲存格內的圖片會留在對應表格格位，因此可在 Word 內繼續編輯，同時維持單頁 A4 方向與版面。

上方「常用」功能列提供新增／開啟／儲存專案、剪下複製貼上、字型字級、粗體斜體底線刪除線、文字與標記顏色、項目符號／編號、縮排、段落對齊、行距和搜尋取代。文字格式會套用到目前選取的獨立文字框。
